# DeskLink

**Mac과 Windows PC를 한 책상처럼.** 마우스·키보드 하나로 두 컴퓨터를 오가고, 클립보드(글자·이미지)와 파일을 주고받습니다.
두 컴퓨터가 같은 네트워크(같은 공유기/Wi‑Fi)에서 **직접, 암호화된 연결**로 통신합니다. 계정·클라우드 서버가 필요 없습니다.

## 할 수 있는 것

| 기능 | 설명 |
| --- | --- |
| 🖱 마우스·키보드 공유 | 마우스를 화면 끝으로 밀면 다른 컴퓨터로 넘어갑니다. 반대쪽 끝으로 밀면 돌아옵니다. 클릭·더블클릭·드래그·스크롤·앞/뒤 버튼 모두 전달됩니다. |
| ⌨️ 맥↔윈도우 단축키 | `Cmd`↔`Ctrl`을 자동으로 바꿔서 Mac 키보드의 `Cmd+C`가 Windows에서 `Ctrl+C`가 됩니다 (반대도 마찬가지). |
| 🇰🇷 한/영 전환 | Mac 키보드로 Windows를 조종할 때 `Caps Lock` = 한/영 키. Windows의 한/영 키로 Mac을 조종하면 Mac 입력 소스(한글↔ABC)가 바뀝니다. |
| 📋 클립보드 | 한쪽에서 복사하면 다른 쪽에서 바로 붙여넣기 (글자, 이미지·스크린샷). 비밀번호 관리자에서 복사한 항목은 보내지 않습니다. |
| 📁 파일 보내기 | DeskLink 창에 파일을 끌어다 놓으면 상대 컴퓨터의 `다운로드/DeskLink` 폴더로 갑니다. |
| 🔐 보안 | 처음 한 번 6자리 코드로 페어링. 이후 페어링된 컴퓨터만 연결되고 모든 내용은 암호화됩니다. |

## 다운로드

1. GitHub 저장소 → **Actions** 탭 → **DeskLink 빌드 (Mac / Windows)** → 가장 최근 성공(✅)한 실행을 엽니다.
2. 페이지 아래 **Artifacts**에서
   - Mac: **DeskLink-mac** (안에 `.dmg`)
   - Windows: **DeskLink-windows** (안에 `DeskLink.exe`)
   를 내려받습니다.

> 다운로드 링크가 있는 Releases 페이지를 원하면: Actions → DeskLink 빌드 → **Run workflow** → "GitHub Release(다운로드 페이지)도 만들기" 체크 → Run.

## 설치

### Mac (Apple 실리콘·Intel 모두)

1. `.dmg`를 열고 **DeskLink**를 **Applications** 폴더로 끌어다 놓습니다.
2. 처음 열 때 "확인되지 않은 개발자" 경고가 나오면
   **시스템 설정 › 개인정보 보호 및 보안** 맨 아래의 **그래도 열기**를 누릅니다.
   (안 되면 터미널에서 `xattr -dr com.apple.quarantine /Applications/DeskLink.app` 실행 후 다시 열기)
3. **손쉬운 사용 권한 주기** (마우스·키보드 공유에 필수):
   DeskLink 창 위쪽의 **권한 요청** 버튼 → **시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용**에서 DeskLink를 켭니다.
   **입력 모니터링** 목록에 DeskLink가 있으면 그것도 켭니다. 켠 뒤 DeskLink를 **종료하고 다시 실행**하세요.
4. "로컬 네트워크의 기기를 찾도록 허용" / 방화벽 질문이 나오면 **허용**.

### Windows

1. `DeskLink.exe`를 원하는 폴더(예: `문서`)에 두고 실행합니다.
2. "Windows의 PC 보호" 창이 나오면 **추가 정보 → 실행**.
3. Windows 방화벽 창이 나오면 **개인 네트워크**에 체크하고 **액세스 허용**.
   (Wi‑Fi가 "공용 네트워크"로 되어 있으면 설정 › 네트워크에서 **개인**으로 바꾸세요.)
4. 시작할 때 자동 실행하려면: `Win+R` → `shell:startup` → 열린 폴더에 DeskLink.exe의 **바로가기**를 넣습니다.

## 처음 연결하기

1. 두 컴퓨터에서 DeskLink를 실행합니다. 잠시 후 **같은 네트워크의 컴퓨터** 목록에 상대가 나타납니다.
2. 한쪽에서 **페어링**을 누르면 다른 쪽 화면에 **6자리 코드**가 뜹니다. 그 코드를 페어링을 누른 쪽에 입력합니다.
3. **화면 배치**에서 상대 컴퓨터가 어느 쪽에 있는지 고릅니다.
   예) 책상 왼쪽에 Mac, 오른쪽에 Windows → Mac에서는 **오른쪽**, Windows에서는 **왼쪽**.
4. 끝! 다음부터는 두 컴퓨터에서 DeskLink를 켜기만 하면 자동으로 연결됩니다.

목록에 상대가 안 보이면 **IP 주소로 직접 연결**을 펼쳐서 상대 컴퓨터 DeskLink 창 맨 아래에 적힌 IP를 입력하세요.

## 사용법

| 하고 싶은 것 | 방법 |
| --- | --- |
| 다른 컴퓨터로 넘어가기 | 마우스를 정한 쪽 화면 끝으로 밀기 |
| 돌아오기 | 반대쪽 끝으로 밀기, 또는 **양쪽 Shift를 동시에** |
| 실수로 자꾸 넘어갈 때 | 설정 › **넘어가기 전 멈춤**을 100~200ms로 |
| 상대 화면에서 포인터가 느리거나 빠를 때 | 설정 › **상대 화면에서 포인터 속도** |
| 클립보드 공유 끄기 | 설정 › 클립보드 공유 체크 해제 |
| 파일 보내기 | 창에 파일 끌어다 놓기, 또는 **파일 선택…** |
| 창 닫기 | 빨간 닫기 버튼은 최소화(계속 실행). 완전히 끄려면 **DeskLink 종료** |

- 마우스 버튼을 누른 채(창을 끄는 중 등)에는 화면 끝에서 넘어가지 않습니다.
- 화면 모서리(핫 코너, 시작 버튼)에서는 넘어가지 않습니다.
- 연결이 끊기면 마우스·키보드는 즉시 원래 컴퓨터로 돌아옵니다.

## 문제 해결

- **Mac에서 마우스가 넘어가지 않거나 Mac 키보드가 안 먹힘**
  손쉬운 사용 권한을 확인하세요. DeskLink를 새 버전으로 바꾼 뒤에는 권한을 다시 줘야 합니다:
  손쉬운 사용 목록에서 DeskLink를 선택해 **–**로 지우고 다시 추가(또는 켜기) → DeskLink 재실행.
- **Windows를 조종하는 중인데 Mac 키보드 입력이 Mac 쪽에 들어감**
  Mac에서 비밀번호 입력란이 열려 있거나 터미널의 "보안 키보드 입력"이 켜져 있으면 macOS가 키보드를 다른 앱이 못 보게 막습니다. 그 창을 닫거나 기능을 끄세요.
- **Windows의 관리자 권한 창(작업 관리자, 관리자 터미널 등)에서만 조작이 안 됨**
  Windows 보안 규칙 때문입니다. DeskLink.exe를 **관리자 권한으로 실행**하면 됩니다.
- **서로 목록에 안 보이고 IP로도 연결이 안 됨**
  같은 공유기에 연결돼 있는지, Windows 방화벽에서 DeskLink가 허용됐는지 확인하세요.
  회사·학교·카페 Wi‑Fi는 기기끼리 통신을 막는 경우가 많습니다. 사용하는 포트: TCP 47810, UDP 47811.
- **"포트 47810을 다른 프로그램이 쓰고 있습니다"**: DeskLink가 이미 실행 중입니다 (Dock/작업 표시줄 확인).
- **"페어링이 삭제되었습니다"**: 한쪽에서 페어링을 지웠습니다. 목록에서 **페어링**을 다시 누르세요.
- **기록 파일** (문제 보고용)
  Mac: `~/Library/Application Support/DeskLink/desklink.log`
  Windows: `%APPDATA%\DeskLink\desklink.log`

## TwinDesk와 다른 점

DeskLink는 두 컴퓨터(Mac ↔ Windows)를 한 쌍으로 쓰는 데 집중한 작은 앱입니다. 다음 기능은 **없습니다**:
두 번째 모니터로 쓰기(확장/미러링), 안드로이드 폰 연결, 카메라·소리 공유, 화면 끝으로 파일 끌어 옮기기, 3대 이상 동시 연결, 자동 업데이트.

## 보안

- 처음 연결할 때 6자리 코드로 페어링합니다 (SPAKE2). 코드를 모르는 사람은 페어링할 수 없고, 네트워크를 엿봐도 코드를 알아낼 수 없습니다.
- 연결은 Noise 프로토콜(X25519, ChaCha20‑Poly1305)로 암호화되고, 페어링된 컴퓨터의 키가 아니면 거부합니다.
- 클라우드나 중계 서버를 쓰지 않습니다. 컴퓨터 이름만 같은 네트워크에 알립니다(찾기용).
- 설정·키 파일: Mac `~/Library/Application Support/DeskLink/config.json`, Windows `%APPDATA%\DeskLink\config.json`.

## 개발

```bash
cd desklink
cargo test            # 단위 테스트 + 두 엔진을 실제 TCP로 연결하는 종단 간 테스트
cargo run             # 실행
```

| 파일 | 내용 |
| --- | --- |
| `src/engine/` | 연결 관리, 페어링, 화면 끝 넘어가기, 클립보드·파일 전송 |
| `src/transport.rs` | Noise 암호화 채널, SPAKE2 페어링 |
| `src/platform/mac.rs` | macOS 입력 가로채기(CGEventTap)·입력 만들기(CGEventPost) |
| `src/platform/windows.rs` | Windows 저수준 훅·SendInput |
| `src/keys.rs` | 맥/윈도우 키 코드 ↔ USB HID 코드 |
| `src/geometry.rs` | 모니터 배치, 넘어가는 지점 계산 |
| `src/ui.rs` | 창(egui) |
