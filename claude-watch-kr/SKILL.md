# 영상 분석 (한국어)

영상 링크를 받으면 **반드시 아래 순서대로** 한다. 대본만 읽고 답하지 않는다 — 화면을 직접 본다.

## 1. 추출

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Users\<사용자>\.claude\skills\claude-watch-kr\watch.ps1" -Url "<영상링크>"
```

- 옵션: `-Model large-v3` (더 정확, 느림) · `-MaxFrames 60` (긴 영상)
- 끝나면 작업 폴더 경로와 프레임 장수·컷 시각이 찍힌다.

## 2. 직접 본다

- `frames\` 의 이미지를 **Read 로 전부 읽는다.** 파일명이 곧 초(`012_37.5s.jpg` = 37.5초).
- 처음 3초에 해당하는 프레임은 **한 장씩 따로** 본다. 후킹이 여기서 결정된다.
- `transcript.txt` 를 읽는다. `INFO.txt` 의 컷 시각과 프레임을 맞춰 본다.

## 3. 보고 형식 (항상 한국어)

### 후킹 멘트
> 첫 3초에 나온 말과 화면을 그대로 인용한다. 맨 위에 크게.

### 컷별 표

| 시간 | 화면에 보이는 것 | 화면 텍스트 | 실제 대사 |
|---|---|---|---|

- 컷 시각 기준으로 묶는다. 프레임이 여러 장이어도 같은 장면이면 한 줄.
- 화면 텍스트는 **자막·강조 문구를 본 그대로** 옮긴다. 없으면 `-`.

### 왜 이 구조가 먹히는지
- 컷 속도, 시선 유도, 텍스트 배치, 정보 공개 순서를 근거로 쓴다.
- "좋다/재밌다" 같은 인상평 금지. 몇 초에 뭐가 바뀌는지로 말한다.

### 내 콘텐츠에 적용할 점
- 그대로 따라 할 것 2~3개, 바꿔야 할 것 1~2개.

## 규칙

- 프레임을 안 보고 답하지 않는다. 못 봤으면 못 봤다고 말한다.
- 작업 폴더는 `%TEMP%\watch-*` 다. 분석이 끝나면 지워도 된다.
- 비공개·연령제한 영상은 다운로드가 막힌다. 그러면 그렇다고 말한다.

## 설치된 도구

| | |
|---|---|
| 다운로드 | `python -m yt_dlp` |
| 프레임·음성 | `ffmpeg` / `ffprobe` (winget Gyan.FFmpeg) |
| 음성 인식 | `faster-whisper` (파이썬, 한국어 다국어 모델) |
